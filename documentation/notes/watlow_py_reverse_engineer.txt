1. buildWriteRequest(param, value, data_type, instance)

param = Parameter ID (from watlow manual)
value = value to write to parameter (for example, 50F for setpoint limit)
data_type = float or int (from watlow manual)
instance = corresponds to the channel to read (my code always uses 01)

BACnetPreamble = '55ff'
requestParam = '05'
zone = 15 + address in Hex (address being waht is displayed on each watlow. mine are 1 and 2) (why add 15?)
dataParam = reformats data param from manual (ex 4012) to hex string (4001 -> 04012 -> 040c)

for floats:
additionalHeader = '00000a'
hexData = '0104' + dataParam (ex. 040c) + instance (ex. 01) + '08'
value = struct.pack('>f', float(value)) (returns a bytes object containing the float value as a big-endian float) (4 bytes?)

for integers:
additionalHeader = '030009'
hexData = '0104' + dataParam + instance + '0f01'
value = value.to_bytes(2, 'big') (returns the integer as unsigned two bytes big endian, aka big endian uint16)

# Request Header String:
hexHeader = BACnetPreamble + requestParam + zone + additionalHeader
example: 55ff + 05 + 0f + 00000a
# Convert input strings to bytes:
hexHeader = unhexlify(hexHeader)

# Data portion of request (here the set point value is appended)
hexData = unhexlify(hexData) + value
float example:
0104 + 040c + 01 + 08 + <00000000>
int example:
0104 + 040c + 01 + 08 + 0000<0000> (not sure about those leading zeroes)

"To calculate the value of the last two check bytes ("Data CRC"):

Perform a CRC-16 of the 6 bytes between the first check byte and 
the last two check bytes (in your first example, this would be the bytes 01 03 01 04 01 01),
 with 0xFFFF (-1) as the initial value for the CRC-16, and 0x8408 as the polynomial. 
Then bit-flip (a.k.a. "not", a.k.a. "invert") the result and read it in little-endian."
